# ARCANA ATELIER（Python版）

呪文を唱え、魔法動物を呼び、音で空間に絵を描く ― 音響魔術と共感覚のアトリエ。

ブラウザ版（HTML / Web Audio API / three.js）を、**Python だけで動くデスクトップアプリ**として作り直したものです。
音の合成・立体音響・残響・3D描画は、すべて numpy と pygame で一から実装しています。

## 起動

```bash
pip install -r requirements.txt      # pygame, numpy
python run.py                        # または python -m arcana_atelier
```

ヘッドホン推奨。日本語フォントは自動で探します（macOS: ヒラギノ / Windows: 游ゴシック・メイリオ / Linux: Noto Sans CJK）。
文字が四角く化けるときは、フォントファイルを指定してください。

```bash
ARCANA_FONT=/path/to/font.ttf python run.py
```

## 遊び方

| 操作 | 内容 |
| --- | --- |
| 中央の円をドラッグ | 魔法陣を一筆書きで描く（MAGIC CIRCLE表示） |
| `A`〜`K` | 8つの音を演奏 |
| `Space` | 詠唱（魔法陣の倍音構成から作ったフレーズ） |
| `1` `2` `3` | 魔法陣 / 3Dの聖域 / 2Dの画布 を切り替え |
| `Esc` / ■ぜんぶ止める | すべての音・詠唱・自動筆記・魔法動物を止める |
| 呪文欄に入力して Enter | 呪文を声で詠唱（カナ・ひらがな・ローマ字OK） |
| 3D表示でドラッグ / ホイール | 視点を回す / 寄る（「空中に描く」で光の彫刻を描く） |
| 2D表示でドラッグ | 筆・霧・星屑・墨・魔法陣スタンプ・消しゴムで描く。`Ctrl+Z`で戻す |
| 🖼 額装して保存 | `gallery/` に額装したPNGを保存 |

- 魔法陣 20種 × 属性 8種 × 音階 6種
- 呪文 11種（「ルミナ・ソノーラ」「レクイエス」など）。知らない言葉も、響きから属性が決まる自作の呪文になります
- 魔法動物 12種（リュミエル、ソナギツネ、ソラクジラ、フェニクス、ハーモクラゲ、ティンパノドラコ、ユキウサギ、ホタルビ、カゼリュウ、ツキフクロウ、ウタイルカ、カネガメ）

## しくみ（技術的なポイント）

| モジュール | 内容 |
| --- | --- |
| `glyphs.py` | 魔法陣を256点に再標本化 → 複素DFT → エピサイクル（精霊）と、x(t) の実フーリエ級数（=音の倍音）を計算 |
| `synth.py` | 波形テーブル発振、ADSR、FFTフィルタ、**バイノーラル定位**（Woodworthの両耳間時間差 + Brown & Dudaの頭部陰影 + 後方の高域減衰）、指数減衰ノイズIRの**FFT畳み込み残響**、**フォルマント合成による呪文の歌声**（母音ごとの共鳴を加算合成で再現）、魔法動物の鳴き声 |
| `world.py` | 属性ごとの音の軌道、音階、呪文、カナ／ローマ字 → 音節（母音・子音）解析、魔法動物の動き |
| `render3d.py` | OpenGLを使わない**自前の3D描画**（オービットカメラ、numpyでの透視投影、ワイヤーフレーム、最大3万粒の光の彫刻を画素に加算描画） |
| `canvas.py` | 共感覚パレット（スクリャービンの色彩対応・五度圏・金箔と群青）、属性ごとの筆致、曼荼羅対称、元に戻す、額装PNG |
| `app.py` | UI・入力・状態管理。音の合成は別スレッドで行い、画面が止まらないようにしている |

音を空間に置くとき、3D表示では**カメラの向きが聞き手の向き**になります。視点を回すと、音の聞こえる方向も一緒に回ります。
